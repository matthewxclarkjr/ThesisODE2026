# Thesis Defense Beamer Presentation

Source for the Beamer presentation accompanying **Finite-Time Blow-Up and Stopping Times for Nonlinear ODEs**.

## Build

Compile `main.tex` with **LuaLaTeX** twice to resolve slide counters and references. Keep `beamer_assets/` adjacent to `main.tex` so the graphics load correctly.

This source package includes the complete presentation (38 main slides and 8 backup slides, 46 frames overall) and the six figures referenced by the TeX file.

## Versioning

Use Git commit history for updates; retain the stable filename `main.tex` and folder name `Beamer` for future revisions.
